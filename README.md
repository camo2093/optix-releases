# OPTIX

**Better Performance. More Control.**

OPTIX is a PC optimization suite for Windows 10 and 11 (x64). It analyzes your system, shows the measured evidence, and changes something only after you confirm it.

## Download

Get the latest installer from the [releases page](https://github.com/camo2093/optix-releases/releases/latest). The file is named `OPTIX-Setup-<version>-x64.exe`. The .NET runtime is included.

## Features

- 20 modules in five groups: General, Gaming, System, Diagnostics, Management.
- Dashboard, PC analyzer, performance advisor and smart optimize.
- Gaming presets, benchmark with optional PresentMon, game profiles and input latency indicators.
- Windows tweaks, process manager, startup manager, hardware health, driver center and system cleaner.
- Network optimizer, crash analyzer and monitoring.
- Optimization history and Restore Center.
- Light and dark mode, accent colors, Inter typeface and Lucide icons.

## Safety

- Every change asks for confirmation first.
- Every change is journaled and can be undone.
- Windows Defender, Firewall, Windows Update and UAC are never modified.
- Anti-cheat processes are never touched.
- Values that cannot be measured are shown as "n/a". OPTIX does not invent numbers.
- The cleaner moves files to the Recycle Bin.

## Administrator rights

OPTIX starts as a standard user. CPU temperatures, disk SMART data, restore points, machine-wide changes and PresentMon capture need administrator rights. You can restart OPTIX elevated, or turn on Always start as administrator in Settings.

## Upgrading from Orbit

Run the new installer. It upgrades in place, and your settings, undo history and tools are migrated automatically.

## SmartScreen

The installer is not code-signed. Windows SmartScreen may show a warning. Select More info, then Run anyway, if you trust the download.
