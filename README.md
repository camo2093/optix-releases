# Orbit

**Better Performance. More Control.**

Orbit is a PC optimization suite for Windows 10/11 (x64) with a monochrome space design.

## Download

👉 **[Download the latest version](https://github.com/leon2093/orbit-releases/releases/latest)** – `Orbit-Setup-<version>-x64.exe`

.NET is included; no extra installation needed. The installer is not code-signed yet, so Windows SmartScreen may show a warning: click *More info → Run anyway*.

## Features

- **Dashboard** with live CPU, GPU, RAM and storage data and a system health score
- **PC Analyzer, Performance Advisor, Smart Optimize** – transparent analysis with evidence, risk and benefit for every suggestion
- **Gaming** – optimization presets, game profiles, FPS benchmark (via Intel PresentMon), bottleneck detection, input-latency diagnostics
- **System** – Windows tweaks, process manager, startup manager, hardware health (temperatures, SMART), driver center, system cleaner
- **Diagnostics** – network optimizer with stability monitor, crash analyzer, live monitoring with CSV export
- **Management** – complete change history and Restore Center to undo supported changes

## Safety

- Every system change requires your confirmation, is logged and – where technically possible – reversible
- Only real measurements – unavailable values are shown as "n/a", never invented
- No changes to Defender, Firewall, Windows Update or UAC
- No interaction with anti-cheat systems

Some data (CPU temperatures, SMART values, restore points, FPS capture) requires running Orbit as administrator.
